# Capture the real Nanjie

Prefer shooting while empty, with the owner's permission.

- Draw one rough floor plan per floor. Mark entrance, stairs, bar, tables/chairs, pool table, DJ booth, speakers, TV and blackboard.
- Give tables simple temporary labels: G01, G02, U01, etc. Match these labels in your photos.
- Record a slow continuous walk around each floor, including the route up the stairs.
- Photograph each room from all corners, plus the front and sides of important fixtures.
- Record approximate room dimensions and one known measurement per area for scale.
- Note fixed furniture versus things staff regularly move.
- Photograph the drinks menu separately if the owner agrees.
- Avoid collecting customer faces or private conversations; architectural reference is sufficient.

The current sample map does not represent the actual bar. Keep original reference files outside the app's distributable `miniprogram` directory.
